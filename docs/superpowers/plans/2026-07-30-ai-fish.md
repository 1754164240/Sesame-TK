# AI 摸鱼功能实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在神奇海洋中增加可自动找回被抓鱼、完成主场景任务、领取摸鱼次数并执行摸鱼的开关，同时为第二版设置页增加全局搜索并保持其为默认 UI。

**Architecture:** 使用独立 Kotlin 协议解析和工作流隔离 AI 摸鱼状态机，使用 Java 友好的网关接口连接现有 `AntOcean` 与 RPC 静态方法。设置搜索使用纯 JavaScript 合同函数，Semi Design 页面只管理输入和渲染状态。

**Tech Stack:** Java 17、Kotlin、`org.json`、JUnit 4、Android Gradle Plugin、React/Semi Design 内嵌页面、Node.js 内置测试运行器。

## 全局约束

- 所有新增和修改文件使用 UTF-8 编码且无 BOM。
- 新增代码注释必须使用中文。
- AI 摸鱼配置代码为 `aiFish`，显示名称为 `AI摸鱼`，默认关闭。
- 主任务场景固定为 `ANTAIFISH`；救援场景固定为 `ANTAIFISH_RESCUE_AND_RESTORE`。
- 对主场景所有 `TODO` 任务各尝试一次通用完成 RPC；救援场景不得调用通用完成和领奖 RPC。
- 服务端等待秒数限制在 0 到 60 秒；救援等待增加 1 秒安全余量。
- 第二版设置 UI 继续使用持久化值 `web`，不得覆盖用户已保存的 `new`。
- 未获得提交授权，不执行 `git add`、`git commit`、`git push` 或创建 PR。
